# Carbon material

Carbon uses black framing, neutral charcoal panels, rounded corners and small gutters. The reference is Spotify's [published desktop interface](https://webplayer.byspotify.com/) and [desktop redesign screenshots](https://newsroom.spotify.com/2023-06-20/spotify-desktop-experience-redesign-your-library-now-playing-views-customize/). No Spotify assets, branding or source code are copied.

Light mode is a light adaptation of the same surface hierarchy. Appearance modes and accents remain independent of the material.
