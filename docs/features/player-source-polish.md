# Player and source polish

Keep the existing aluminium appearance and blue accent while reducing visual clutter.

- Put play/pause beside the current track details. Let the seek control use the remaining space, including on wide windows. Keep volume and the download selector reachable.
- Make each audio row clearly distinguish the selected Discogs track, which supplies the saved title and tags, from the YouTube upload, which supplies the audio. Show the verified upload title when available and the saved source title offline.
- Keep rows compact: one track selector, a clearly labelled YouTube title, a short match/saved state and the relevant download/play/tag actions. Make partial tagging notes expandable. Keep source failures visible and retryable.
- Preserve manual assignment, multiple sources per track, offline playback and retagging.
- Provide an original restrained record-and-needle icon for Linux PNG, Windows multi-resolution ICO and macOS ICNS. Use it in the native window, macOS Dock, app header and browser favicon. Keep its source and generation/check command in the repository.

Validate compact and wide windows in both themes, run the existing functional suites and verify native icon formats. Native execution is tested on Linux; Windows/macOS export formats follow their documented containers. Installer creation remains a separate release concern.
